# 0.1.0-alpha

## 简体中文

Magic Shulker Boxes（魔法潜影盒）首个公开 Alpha 版本，适用于 Minecraft Java **1.21.11 / Fabric / Java 21**。

- 背包溢出的拾取物依次进入同类专用盒、空盒、杂物盒；可开启其他单类盒兜底。
- 兼容 Carpet 潜影盒堆叠，修改内容前安全拆出一个盒子。
- 自动腾出栏位：直接收纳、丢出后回收或禁用；支持零散物品和杂物盒复用。
- 服务端可统一配置或允许玩家个人设置，总开关始终由服务端控制。
- 中英文提示、命令和 Mod Menu + YACL 图形设置。

安装 `magic-shulker-boxes-fabric-0.1.0-alpha+mc1.21.11.jar` 和对应版本的 Fabric API。`-sources.jar` 是源码包，不放入 `mods`。客户端图形设置另需 Mod Menu 与 YACL；专用服务端不需要这两项。Carpet 可选，本模组不会自动开启堆叠规则。

这是 Alpha 预发布，建议先在测试存档验证所用模组组合。此前本地测试包使用过 1.x 编号，升级本次首发时请移走旧包，只保留一个本模组 JAR。

[中文文档](https://chenjicheng.github.io/magic-shulker-boxes/) · [源代码 / MIT](https://github.com/chenjicheng/magic-shulker-boxes)

## English

The first public Alpha release of Magic Shulker Boxes, for Minecraft Java **1.21.11 / Fabric / Java 21**.

- Store pickup overflow in matching, empty, then mixed shulker boxes, with an optional single-type fallback.
- Support Carpet shulker stacking by safely separating one box before changing its contents.
- Free inventory slots through direct storage or drop-and-recollect, including partial stacks and mixed-box reuse.
- Enforce server defaults or allow personal preferences, while retaining the server master switch.
- Chinese and English messages, commands, and an optional Mod Menu + YACL settings screen.

Install the regular JAR and matching Fabric API. Do not install the sources JAR. Mod Menu and YACL are needed only for the client settings screen; Carpet is optional and its stacking rule must be enabled separately.

This is a prerelease. Check your mod combination in a test world first. Earlier local development builds used 1.x versions; remove those JARs before installing this first public release.
