# Magic Shulker Boxes 0.10.0

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- 新增手动杂物盒槽位。自行绑定“指定杂物盒格子”快捷键，默认未绑定，支持键盘与鼠标；按住并划过自己的主背包或快捷栏可多选，首格决定整轮指定或取消，重复经过不会翻转。
- 角色绑定固定格子，不写入盒子名称或物品数据。各世界、各玩家独立保存；空格和普通物品保留标记，换入潜影盒即可收纳。装备、副手和外部容器不能指定。
- 收纳顺序为同类专用盒 → 指定杂物盒 → 空盒。指定盒为空或只有一种物品时仍保留杂物角色；未指定的混合盒不会自动接收杂物。默认实际入包物仍优先同类盒，`preferEmptyBoxesOverInventory` 开启后才尝试杂物盒与空盒。
- 左上小盒子角标用青色、灰色、黄色分别表示有效盒、无盒、待确认；悬停显示状态与按键。提示框显示在角标和多选边框上方，不遮挡提示文字。
- 指定格不被自动腾栏或当作拆盒/取料空位。兼容 Carpet 堆叠，拆分后装有物品的单盒留在指定格；所有盒子及内容数量保留。丢出回收仅在原版拾取后路由实际收到的数量。
- IPN 2.2.6 整理保留指定格，不修改其保存的锁定设置或普通补货筛选。其他整理模组需使用自己的固定格功能。
- 保留 0.9.2 的原版优先和未知容器所有权保护。已有设置不重置，配置版本 2 与设置/GUI 协议 v7 不变；槽位状态使用独立协议和玩家数据文件。

槽位选择与角标需要两端都升级到 0.10.0。升级后在“选项 → 控制 → 按键绑定 → 魔法潜影盒：槽位选择”绑定按键。完整操作见[使用说明](../guide.md)，部署流程见[手动部署](../release-staging.md)。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- Adds manually assigned junk box slots. Bind **Assign junk box slots** to a keyboard key or mouse button; it starts unbound. Hold it while crossing your own inventory or hotbar slots. The first valid slot chooses assign or erase for the gesture, and revisits do not toggle again.
- Roles belong to fixed positions without renaming or tagging items. Each player and world saves independently. Empty slots and ordinary items retain the marker; a shulker placed there becomes usable. Equipment, offhand and external containers cannot be assigned.
- Storage priority is matching single-type boxes → assigned junk boxes → empty boxes. Assigned empty or single-type boxes retain their role; unassigned mixed boxes do not become junk boxes. Default post-insertion storage still prefers matching boxes; `preferEmptyBoxesOverInventory` also permits junk and empty boxes.
- Top-left markers show aqua for a usable box, gray for no box and yellow for pending changes. Hover for status and the current binding. Tooltips render above markers and selection outlines.
- Assigned slots are protected from automatic eviction and empty split/extraction destinations. Carpet stack splitting leaves the filled single box in its assigned position and conserves boxes and contents. Drop recollection routes only quantities actually received after vanilla pickup.
- IPN 2.2.6 sorting preserves assigned slots without changing stored locks or ordinary refill matching. Other sorting mods need their own fixed-slot facilities.
- Retains 0.9.2 vanilla-first processing and unverified-container ownership protection. Existing settings stay intact; disk configuration version 2 and settings/GUI protocol v7 remain unchanged. Slot state uses independent channels and player data files.

Update both sides to 0.10.0 for selection and markers. Bind the key under **Options → Controls → Key Binds → Magic Shulker Boxes: slot selection**. See the [user guide](../en/guide.md) and [manual deployment](../en/release-staging.md).
