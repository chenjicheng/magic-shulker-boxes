# Magic Shulker Boxes 0.10.1

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- “指定杂物盒格子（按住多选）”默认按键改为 **F9**。打开背包，把鼠标放到自己的格子上按键；按住可划过多格。
- 沿用 Minecraft 保存的自定义绑定，不覆盖已有按键选择。0.10.0 保存的“未绑定”可在“选项 → 控制 → 按键绑定 → 魔法潜影盒：槽位选择”点击该行“重置”，恢复 F9，或自行重新绑定。
- 保留 0.10.0 的槽位角色、收纳保护、IPN 整理和提示层次。服务端配置与玩家槽位数据不变。

详见[使用说明](../guide.md)。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- **Assign junk box slots** now defaults to **F9**. Hover your own inventory slot and press it; hold while crossing slots for multiple selections.
- Retains Minecraft's saved custom bindings. If 0.10.0 saved an unbound choice, use **Reset** on this row under **Options → Controls → Key Binds → Magic Shulker Boxes: slot selection** to restore F9, or bind a key manually.
- Preserves 0.10.0 slot roles, storage protection, IPN sorting and tooltip layering. Server settings and saved player slot choices are unchanged.

See the [user guide](../en/guide.md).
