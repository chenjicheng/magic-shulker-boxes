# 0.11.0

## 简体中文

- 模组从真实空盒自动分配并标记单个受管杂物盒，保留原有内容盒用途；移除 F9 固定格选择与额外 IPN 锁投影，旧角色文件保留但不读取。
- 同类达到三组（64上限为192个、16上限为48个、不可堆叠为3件）时，完整归集受管盒内同类存量到专用盒；纯盒可原地升级，放不下则不做半次迁移。
- 整次原版多格入包共享真实净增预算，三组收据可完整规划专用盒；保留来源扣减、未知菜单保护与 MOVE/DROP 数量/组件守恒。
- 标记只在背包/快捷栏内保留；自己的背包光标临时整理保留；外部容器光标、外部容器、副手/装备、移除结果、地面与放置会清除，返回不会恢复。其他自定义数据、名称与内容保留。
- 快捷栏默认不腾栏，新增第1–9格独立保护设置，沿用继承、权限、保存与普通设置按键。
- 设置与GUI协议为v8，两端使用这些界面需一起更新；磁盘配置版本2及旧选择保留。

## English

- Allocate and mark one managed junk box from real empty stock while protecting original contents. Remove F9 slot assignment and extra IPN lock projection; retain old role files without reading them.
- At three stacks (192 for a limit of64, 48 for16, or three unstackable items), completely gather matching managed contents into dedicated storage. Pure boxes can promote in place; incomplete plans remain unchanged.
- Budget whole vanilla multi-slot receipts once per full-component variant and plan dedicated storage for three-stack receipts. Preserve source deductions, unknown-menu ownership and MOVE/DROP conservation.
- Roles remain inside backpack/hotbar positions and preserve temporary own-inventory cursor arrangement and clear on external-cursor/container/equipment/removal/ground/placement boundaries. Returning does not restore them; other metadata and contents survive.
- Hotbar relocation remains off; add independent protection for positions1–9 using existing inheritance, permissions, persistence and key binds.
- Settings/GUI use v8 and require both sides to update; disk schema2 and old choices remain intact.
