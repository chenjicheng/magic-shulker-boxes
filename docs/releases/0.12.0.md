# Magic Shulker Boxes 0.12.0

## 简体中文

本次公开发行也包含 [0.11.0 的自动杂物盒、三组分离和快捷栏逐格保护](0.11.0.md)。

- 新增“每次取料数量”，支持 1–64，用于投影取料和 IPN 补货。实际取出不超过来源库存和物品自身堆叠上限：不可堆叠物品为 1 件，16 件上限物品最多取 16 件，也支持组件定义的其他上限。
- 个人设置可跟随服务器，房主和管理员可配置默认值及逐项权限。旧“每次取一组”自动迁为 64 或 1，原配置先备份。
- 重写全部中英文设置、命令、快捷键和反馈文案，统一术语并说明失败后的可用操作。
- 客户端和服务端需同时更新；合成按配方取料、工具替换为 1 件，GCA 独立补货不变。

## English

This public release also includes [0.11.0’s automatic junk boxes, three-stack consolidation and per-slot hotbar protection](0.11.0.md).

- Added “Items per refill”: choose 1–64 for schematic and IPN refilling. Extraction respects available items and their stack limit: 1 for unstackable items, at most 16 for items capped at 16, including component-defined limits.
- Personal settings can inherit server defaults. Hosts and administrators control defaults and permissions. The retired full-stack switch migrates to 64 or 1 after backing up the original configuration.
- Rewrote all Chinese and English settings, commands, keybinding labels and feedback for consistent terms and actionable recovery.
- Update client and server together. Crafting follows recipes, tool swaps take 1 and GCA’s independent replenishment is unchanged.
