# Magic Shulker Boxes 0.13.0

## 简体中文

- 快捷栏第 1–9 格保护改为默认开启。自动腾栏不会移走这些格子的物品，自动拆盒也不会把新盒放到这些格子；`useHotbarForSpace` 仍默认关闭，两者相互独立。
- 升级时自动迁移已有服务端配置、玩家个人设置和单人客户端配置：服务端配置补齐九项保护，个人稀疏覆盖把显式关闭改为开启，未设置的格子继续继承服务器默认值。迁移只执行一次，之后仍可逐格关闭。
- 原始配置在迁移前完整备份；没有更早迁移备份时使用 `.pre-0.13.0.bak`。无效字段或冲突备份保持原文件不变。
- 磁盘配置版本升至 3；设置与 GUI 协议保持 v9。客户端和服务端需同时更新到 0.13.0。

## English

- Hotbar positions 1–9 are now protected by default. Automatic relocation does not move their items, and automatic box splitting does not place a new box there. `useHotbarForSpace` remains off by default and independent.
- Upgrading migrates existing server configuration, player preferences and single-player client settings: server files get all nine protections, sparse personal overrides flip explicit off values, and absent keys keep inheriting the server default. Migration runs once, and positions can still be unprotected afterward.
- Original files are backed up before migration; migrations without an earlier backup use `.pre-0.13.0.bak`. Invalid fields or conflicting backups leave the original unchanged.
- Disk configuration is now version 3; settings and GUI stay on protocol v9. Update client and server together to 0.13.0.
