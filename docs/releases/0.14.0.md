# Magic Shulker Boxes 0.14.0

## 简体中文

- 新增：原理图取料优先使用快捷栏。选中格为空时直接放入，否则使用任意快捷栏空格；快捷栏全满时替换选中格（不可替换时扫描其他格），跳过工具和可损坏物品。
- 新增：被替换物品优先回到来源盒；放不下的部分再按同类专用盒、受管杂物盒、空盒、背包空格收纳。没有安全空间时整笔拒绝，不修改物品。
- 新增：服务端临时来源账本，记录来源盒子、剩余数量、已回盒和已转存数量；不写入物品 NBT 或组件，物品离开主背包与快捷栏、玩家死亡或退出登录后清除，不跨服务端重启保留。
- 新增：`/msb ledger` 查看本人的来源条目，管理员可用 `/msb admin ledger <玩家>` 查看在线玩家。
- 新增：主背包或快捷栏中被跟踪的物品悬停显示来源盒子和可回盒数量；由账本同步渲染，不修改物品名称、Lore 或图标。
- 新增：取料守恒审计，仅在取出、剩余、已回盒、已转存计数异常时记录错误日志。
- 变更：`refillMakeSpace=false` 时不再替换非空快捷栏格，材料保留背包落点。
- 变更：`useEmptyBoxes=false` 现在覆盖腾栏、取料替换、工具替换、合成余量和堆叠空盒拆盒捷径；已标记的受管杂物盒仍然可用。
- 变更：回原盒遵守当前的 `enderChestRefill` / `includeOffhand` 开关；关闭后对应的末影箱或副手盒子不再写入。
- 改进：唯一同指纹堆在主背包或快捷栏内移动时跟随该堆；出现多堆同物品或物品离开物品栏时放弃来源，避免错误回退。
- 修复：关闭“启用空盒”后，腾栏路径仍可能从未标记空盒新建受管盒。
- 修复：快捷栏满时取料总落背包、旧手持物被换入背包，导致连续取料逐渐塞满背包。
- 兼容：磁盘配置版本保持 3，设置与 GUI 协议保持 v9；来源提示使用新增的只读通道，旧客户端不会注册。建议客户端和服务端同时更新到 0.14.0。

## English

- Added: schematic refilling now prefers the hotbar. An empty selected slot is filled first, otherwise any empty hotbar slot is used; when full, the selected slot is replaced (scanning other slots when needed), skipping tools and damageable items.
- Added: a replaced stack returns to its source box first; the remainder follows matching dedicated boxes, managed junk boxes, empty boxes and free backpack slots. With no safe space, the whole refill is refused without changing items.
- Added: a transient server-side provenance ledger recording the source box, remaining quantity, returned count and stored count. Nothing is written to item NBT or components; entries clear when items leave the main inventory and hotbar, on death or logout, and are not kept across server restarts.
- Added: `/msb ledger` for the caller's entries and `/msb admin ledger <player>` for an online player.
- Added: tracked items in the main inventory or hotbar show their source box and returnable count in the tooltip, rendered from the ledger without changing names, lore or icons.
- Added: a conservation audit that logs only when extracted, remaining, returned or stored counts violate the invariant.
- Changed: with `refillMakeSpace=false`, a non-empty hotbar slot is never replaced and the backpack destination remains.
- Changed: `useEmptyBoxes=false` now covers relocation, schematic and tool replacement, crafting remainders and the stacked-empty-box shortcut; already marked managed junk boxes remain usable.
- Changed: returns honor the current `enderChestRefill` / `includeOffhand` switches; disabling one stops writes to that ender chest or offhand box.
- Improved: a unique matching stack is followed while it moves within the main inventory or hotbar; duplicate stacks or an item leaving the inventory discard provenance instead of risking a wrong return.
- Fixed: disabling empty boxes still allowed the relocation path to create a managed box from unmarked empty stock.
- Fixed: with a full hotbar, refilled materials always landed in the backpack and the old held stack was swapped into it, gradually filling the backpack during continuous refills.
- Compatibility: disk configuration stays at version 3 and settings/GUI stay on protocol v9; provenance uses a separate additive read-only channel that older clients do not register. Update client and server together for 0.14.0.
