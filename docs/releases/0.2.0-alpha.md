# 0.2.0-alpha

Minecraft **1.21.11 / Fabric / Java 21**。

新增 Litematica 轻松放置自动从背包潜影盒取料，支持背包满时直接收纳腾栏。客户端和服务端都需要此版本；原有拾取收纳仍可仅装服务端。取料数量、腾栏和失败提示均可配置；成功时保持安静。

Adds automatic material refilling from inventory shulker boxes for Litematica Easy Place, with optional space-making when the inventory is full. Both sides need this version; pickup storage still works with a server-only installation. Refill quantity, space-making and failure notices are configurable. Successful refills are silent.

设置采用右侧独立切换按钮，左侧固定名称不参与切换；重置图标放大。个人偏好直接显示继承的服务端值；未同步时明确标识。

Settings use separate cycling buttons beside fixed labels, with larger reset icons. Personal preferences display inherited server values inline, with an explicit unknown state before synchronization.
