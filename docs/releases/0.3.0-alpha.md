# 0.3.0-alpha

Minecraft **1.21.11 / Fabric / Java 21**.

## 简体中文

### 本次变更

- 拾取自动入盒与 Litematica 自动取料使用独立开关，可分别继承或覆盖服务端设置。
- 取料优先使用较空的可用盒子；存料在原有同类盒、空盒、杂物盒及兜底分类顺序内，优先填充较满的盒子。
- 取料请求增加物品组件指纹。来源名称等组件在请求途中变化时拒绝取料，避免取出非预期材料；无法可靠编码的临时组件同样拒绝。
- 设置保存超时后查询服务端已确认的值；本地写入失败仍更新当前会话使用的设置。恢复标记可防止重连或重启后把旧本地文件上传覆盖服务端。
- 合并同一盒内等价的失败取料尝试，同时保留不同堆叠数量的兜底机会。在本机固定满背包测试场景中，单请求分配从约 16 MB 降至约 0.67 MB，减少约 96%；该结果不代表多人 TPS 或跨机器耗时保证。

### 升级与安装

安装 `magic-shulker-boxes-fabric-0.3.0-alpha+mc1.21.11.jar` 和对应 Fabric API，使用 Fabric Loader 0.18.4 或更新版。移走旧版模组 JAR；`-sources.jar` 是源码包，不放入 `mods`。

**自动取料需要客户端与服务端同时升级到 0.3.0-alpha**。旧取料协议不再接受；新版个人设置界面保存也需要支持恢复查询的服务端。原有拾取收纳仍可只安装在服务端，客户端无需安装。

`enabled=false` 现在只关闭拾取入盒；若要同时关闭自动取料，请设置 `schematicRefill=false`。其他配置键保持不变。Carpet 堆叠、Mod Menu / YACL 和 Litematica / MaLiLib 仍按[使用文档](https://chenjicheng.github.io/magic-shulker-boxes/guide.html)配置。

验证覆盖 73 项单元测试、普通专用服务端及 Carpet 1.4.194 各 30 项 GameTest，包括真实拾取路径、堆叠拆盒、过期请求、保存恢复及失败规划。中英文文档构建通过；本次没有新增手动图形界面或实际网络延迟测试。此版本仍为 Alpha 预发布。

## English

### Changes

- Pickup storage and Litematica material refilling have independent switches, with separate server inheritance and personal overrides.
- Refilling prefers less-filled eligible boxes. Storage prefers fuller boxes within the existing matching, empty, mixed and optional fallback categories.
- Refill requests carry an item-component fingerprint. Changed names or other source components invalidate a request, preventing extraction of unintended materials. Transient components that cannot be reliably encoded are also refused.
- Timed-out saves query confirmed server preferences. A local write failure still updates active session values; recovery markers prevent stale local files from overwriting server values after reconnecting or restarting.
- Equivalent failed extraction plans within a box are tried once. Different stack counts remain candidates. In a fixed local full-inventory fixture, per-request allocation fell from about 16 MB to 0.67 MB, approximately 96% less; this is not a multiplayer TPS or cross-machine timing guarantee.

### Upgrade and installation

Install `magic-shulker-boxes-fabric-0.3.0-alpha+mc1.21.11.jar` and the matching Fabric API with Fabric Loader 0.18.4 or newer. Remove the old mod JAR; do not put the sources JAR in `mods`.

**Update both client and server to 0.3.0-alpha for material refilling**. The old refill protocol is no longer accepted, and saving personal settings through the new GUI requires server support for recovery queries. Pickup storage still works with a server-only installation.

`enabled=false` now disables pickup storage only. Also set `schematicRefill=false` to disable refilling. Other configuration keys are unchanged. Configure Carpet stacking, Mod Menu / YACL and Litematica / MaLiLib as described in the [user guide](https://chenjicheng.github.io/magic-shulker-boxes/en/guide.html).

Validation covers 73 unit tests and 30 GameTests each on vanilla and Carpet 1.4.194 dedicated servers, including real pickup, stacked boxes, stale requests, save recovery and failed planning. Bilingual documentation builds pass. This release adds no manual GUI or actual network-latency testing and remains an Alpha prerelease.
