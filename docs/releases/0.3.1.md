# 0.3.1

Minecraft **1.21.11 / Fabric / Java 21**.

## 简体中文

**本版会先备份，再一次性重置所有无版本标记的旧配置。拾取自动入盒默认关闭。**

- 重置范围包括服务端统一配置、服务端保存的玩家偏好和客户端偏好。0.3.0-alpha 及更早版本均没有标记，全部按此规则处理。
- 原文件完整备份到同目录的 `<原文件名>.pre-0.3.1.bak`；备份失败或同名备份内容不同，则保留原文件并报错，不覆盖已有备份。
- 服务端恢复默认值（`enabled=false`、`allowPlayerSettings=false`）；个人覆盖项清空，重新继承服务端。已有离线玩家文件也会在服务端启动时处理。此操作只涉及设置，不修改玩家物品、潜影盒内容或世界方块。
- 新配置包含 `configVersion: 1`，此后调整的设置跨重启保留，不重复重置。未知版本、损坏 JSON 和新版非法配置保留并报错。
- 设置同步及图形设置使用新协议，旧客户端无法重新上传旧偏好。使用个人设置时，两端都需升级到 **0.3.1**；纯服务端拾取收纳仍不要求客户端安装。

单人房主可在“世界设置”开启自动入盒；多人服管理员在服务端文件中设置 `enabled=true` 后执行 `/msb admin reload`。需要允许个人设置时，再开启 `allowPlayerSettings`。自动取料与入盒独立，`schematicRefill` 默认仍为 `true`。

安装 `magic-shulker-boxes-fabric-0.3.1+mc1.21.11.jar` 和对应 Fabric API，使用 Fabric Loader 0.18.4 或更新版。移走旧版 JAR；不要将 `-sources.jar` 放入 `mods`。备份不会自动恢复；如需找回特定选择，将所需选项填回新版文件并保留版本标记。详见[中英文使用文档](https://chenjicheng.github.io/magic-shulker-boxes/guide.html)。

验证覆盖旧配置备份与重置、备份冲突/不可写、重启保留、未来版本保护、离线玩家、旧协议隔离、真实拾取及 Carpet 堆叠。本版没有新增手动界面或实际网络延迟测试。

## English

**This release backs up and resets all unversioned settings once. Pickup storage is off by default.**

- The reset covers shared server settings, server-stored player preferences and client preferences. Versions through 0.3.0-alpha had no marker and all follow this rule.
- Exact originals are backed up alongside each file as `<original filename>.pre-0.3.1.bak`. A backup failure or conflicting existing backup preserves the original and reports an error; existing backups are never overwritten.
- Server defaults are restored (`enabled=false`, `allowPlayerSettings=false`); personal overrides are cleared to inherit server settings. Server startup also handles existing offline-player files. Only settings change; player items, shulker contents and world blocks are untouched.
- New files contain `configVersion: 1`. Subsequent edits survive restarts without another reset. Unknown versions, malformed JSON and invalid current-version settings are retained and reported.
- Settings synchronization and the GUI use new channels so old clients cannot re-upload old preferences. Update both sides to **0.3.1** for personal settings; server-only pickup storage still needs no client installation.

Singleplayer hosts can enable pickup storage in World settings. Multiplayer administrators can set `enabled=true` in the server file and run `/msb admin reload`, then enable `allowPlayerSettings` if desired. Material refilling remains independent; `schematicRefill` still defaults to `true`.

Install `magic-shulker-boxes-fabric-0.3.1+mc1.21.11.jar` with matching Fabric API and Fabric Loader 0.18.4 or newer. Remove old JARs; do not install the sources JAR. Backups are not restored automatically. To recover selected choices, copy the desired options into the new file while retaining its version marker. See the [user guide](https://chenjicheng.github.io/magic-shulker-boxes/en/guide.html).

Coverage includes backups and resets, conflicting/unavailable backups, restart persistence, future-version protection, offline players, old-channel isolation, real pickup and Carpet stacking. This release adds no manual GUI or actual network-latency testing.
