# Magic Shulker Boxes 0.3.2

Minecraft **1.21.11 / Fabric / Java 21**.

## 简体中文

允许玩家个人设置时，服务端的自动入盒和自动取料开关现在作为默认值。玩家可以分别开启或关闭两项功能；即使服务端默认关闭，个人开启也会生效。服务端关闭 `allowPlayerSettings` 时，仍由服务端统一决定。

自动入盒配置键从 `enabled` 改为 **`pickupStorageEnabled`**。首次读取 0.3.1 的 `configVersion: 1` 配置时，模组会把原文件完整备份为同目录的 `<原文件名>.pre-0.3.2.bak`，再改写为 `configVersion: 2` 和新键，保留原开关值及其他有效设置。服务端总配置、已有玩家文件（包括离线玩家）及客户端偏好都会处理。若备份冲突、字段无效或文件损坏，原文件保持不变并报错。无版本标记的更旧配置仍按 0.3.1 的备份重置规则处理。迁移只涉及设置，不修改存档、物品或潜影盒内容。

新文件和命令不再接受 `enabled`。个人设置及取料协议升级到 v3，使用这两项功能时客户端与服务端都需更新到 0.3.2；仅由服务端执行拾取入盒的玩家仍可不装客户端模组。

管理员可在服务端 `config/magic_shulker_boxes.json` 保持 `pickupStorageEnabled=false`，并使用 `/msb admin player-settings true` 开放个人设置。玩家随后执行 `/msb set pickupStorageEnabled true` 即可自行启用入盒；`/msb set schematicRefill true` 可独立启用取料。`/msb reset` 恢复继承服务端默认值。旧版客户端需升级才能使用新图形设置和取料通道。

安装 `magic-shulker-boxes-fabric-0.3.2+mc1.21.11.jar` 和对应 Fabric API，使用 Fabric Loader 0.18.4 或更新版。移走旧版 JAR；不要将 `-sources.jar` 放入 `mods`。详见[中文使用文档](https://chenjicheng.github.io/magic-shulker-boxes/guide.html)。

## English

When the server allows personal settings, its pickup storage and material-refill switches now act as defaults. Players can independently turn either feature on or off, including when the server default is off. Turning off `allowPlayerSettings` still enforces the shared server values.

The pickup setting is renamed from `enabled` to **`pickupStorageEnabled`**. On first read, a valid 0.3.1 `configVersion: 1` file is backed up byte-for-byte as `<original filename>.pre-0.3.2.bak` alongside the original, then rewritten with `configVersion: 2` and the new key. Its switch value and all other valid choices are retained. Shared server settings, existing player files (including offline players), and client preferences are covered. Conflicting backups, invalid fields and damaged files remain unchanged with an error. Older unversioned files retain the 0.3.1 backup-and-reset behavior. Migration changes settings only, never worlds, items or shulker contents.

Current files and commands no longer accept `enabled`. Personal settings and refilling use v3 channels; update both client and server to 0.3.2 for these features. Server-only pickup storage still does not require a client mod.

Administrators may leave `pickupStorageEnabled=false` in the server's `config/magic_shulker_boxes.json` and enable personal settings with `/msb admin player-settings true`. A player can then use `/msb set pickupStorageEnabled true` to opt in to pickup storage, and `/msb set schematicRefill true` to enable refilling independently. `/msb reset` restores inheritance from the server defaults. Older clients must upgrade for the new GUI and refill channels.

Install `magic-shulker-boxes-fabric-0.3.2+mc1.21.11.jar` with the matching Fabric API and Fabric Loader 0.18.4 or newer. Remove the old JAR; do not install the sources JAR. See the [English user guide](https://chenjicheng.github.io/magic-shulker-boxes/en/guide.html).
