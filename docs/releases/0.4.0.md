# Magic Shulker Boxes 0.4.0

Minecraft **1.21.11 / Fabric / Java 21**.

## 简体中文

### IPN 消耗品与工具补货

IPN 在普通背包找不到替代物品时，现在可以从背包潜影盒取物。触发时机、药水效果、食物/工具匹配、耐久阈值、禁用补货栏位和排序继续由 IPN 原有规则决定。服务器验证真实来源与目标后取出，IPN 再执行原有主手或副手替换，保留空瓶和旧工具。

新增独立开关 **`ipnRefill=true`**。关闭只停止潜影盒来源扩展，IPN 原有背包补货仍正常。已验证 Inventory Profiles Next **2.2.6**、libIPN **6.6.3**（Fabric 1.21.11）。两端需要 Magic Shulker Boxes 0.4.0；只有客户端需要 IPN 及其依赖。

### 合成材料补货

背包 **2×2** 和工作台 **3×3** 都可从随身潜影盒补充材料：

- 点击配方时补足材料，沿用原版配方权限、布局和 Shift 批量数量。
- 普通点击或 Shift 取出成品后，为耗空格子补回原输入类型及组件；普通背包优先，再查找潜影盒。
- 直接取到合成格，满背包也不需要额外材料栏。整套材料不足或不能安全保存占格余留物时停止补货，不部分抽取。

新增独立开关 **`craftRefill=true`**，不依赖 IPN。服务器安装 0.4.0 即可执行；客户端也更新到 0.4.0 后，原版配方书会统计盒内材料，并在盒内数量变化时刷新。来源包括主背包、快捷栏盒，以及设置允许的副手盒；不支持其他加工菜单、末影箱或嵌套容器。

### 升级与验证

`ipnRefill` 与 `craftRefill` 默认开启，与拾取入盒、原理图取料独立；允许个人设置时可分别覆盖服务端默认值。0.3.2 的 `configVersion: 2` 配置与既有选择保留，无需重置；新开关缺省为开启。较早配置仍按已有备份迁移规则处理。

本次通过 **104 项单元测试**、原版与 Carpet 1.4.194 **各 53 项 GameTest**、真实客户端合成及 IPN 回归。覆盖组件冲突、空间不足、堆叠盒、余留物、重复/过期请求和个人设置。可选客户端库与测试代码不打包进发行 JAR。

安装 `magic-shulker-boxes-fabric-0.4.0+mc1.21.11.jar`，移走旧 JAR，不安装 `-sources.jar`。完整规则见[中文使用文档](https://chenjicheng.github.io/magic-shulker-boxes/guide.html)。

## English

### IPN consumable and tool refilling

When IPN cannot find an ordinary backpack replacement, it can now use backpack shulker-box contents. IPN retains its original triggers, potion/food/tool matching, durability thresholds, disabled refill slots and sorting. The server verifies the real source and target, extracts the candidate, and lets IPN perform its normal main-hand/offhand swap while preserving bottles and old tools.

The independent **`ipnRefill=true`** switch controls this source extension. Disabling it leaves IPN's ordinary backpack refilling intact. Verified with Inventory Profiles Next **2.2.6** and libIPN **6.6.3** for Fabric 1.21.11. Both sides need Magic Shulker Boxes 0.4.0; only the client needs IPN and its dependencies.

### Crafting ingredient refilling

Both the **2x2 inventory** and **3x3 crafting-table** grids can use carried box materials:

- Recipe placement retains vanilla permissions, layout and Shift batch quantities.
- Ordinary output clicks and Shift crafting refill emptied cells with the original input type and complete components, preferring ordinary inventory before boxes.
- Materials go directly into the grid without a temporary backpack slot. Incomplete material sets or unsafe relocation of grid remainders stop refilling without partial extraction.

The independent **`craftRefill=true`** switch requires no IPN. A 0.4.0 server performs extraction; a 0.4.0 client also counts box contents in the vanilla recipe book and refreshes after content changes. Main-inventory/hotbar boxes and optionally offhand boxes are sources. Other processing menus, ender chests and nested containers are excluded.

### Upgrade and verification

`ipnRefill` and `craftRefill` default to enabled, independently of pickup storage and schematic refilling. Allowed personal settings can override each server default. Existing 0.3.2 `configVersion: 2` files and choices are retained without resetting; omitted new switches default to enabled. Earlier configurations retain their existing backup/migration rules.

Verified with **104 unit tests**, **53 GameTests each** in vanilla and Carpet 1.4.194, and real crafting/IPN client tests. Coverage includes component conflicts, capacity, stacked boxes, remainders, duplicate/stale requests and personal settings. Optional client libraries and test code are excluded from the distribution.

Install `magic-shulker-boxes-fabric-0.4.0+mc1.21.11.jar`, remove the old JAR, and do not install the sources JAR. See the [English user guide](https://chenjicheng.github.io/magic-shulker-boxes/en/guide.html).
