# Magic Shulker Boxes 0.5.0

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- 自动收纳支持容器 Shift 转移、普通光标放入背包及村民交易。光标持物不提前收纳；交易产物容量不足时不扣款、不计次数。
- 新增 `enderChestRefill=false`。开启后，原理图、合成与 IPN 可从本人末影箱的直接物品和其中潜影盒取料，无需打开末影箱；随身来源优先。
- IPN 从盒中换工具时，服务器一次完成装备与回存，旧工具返回来源盒中备用工具的原格，保留全部组件。消耗品沿用 IPN 原换手流程。
- 服务端新增 `playerEditableSettings` 设置名数组，控制玩家可以修改的每个选项。未授权项使用服务器值；GUI、命令、同步和运行时均校验。省略数组保留旧的全开放规则，仍受 `allowPlayerSettings` 总开关约束。
- 保留 `configVersion: 2` 和既有个人选择；政策撤权时保留未生效的选择，不删除文件。

GUI、原理图和 IPN 的网络协议已更新，使用这些功能时两端都需升级到 0.5.0。容器与交易收纳仍可仅安装服务端。菜单中不使用丢出腾栏，普通光标放入后的收纳不搬动已有背包物品。详见[使用说明](../guide.md)。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- Storage supports container Shift transfers, cursor deposits into player inventory and villager trades. Cursor items are left alone; insufficient capacity does not charge a trade or increment its uses.
- New `enderChestRefill=false` enables schematic, crafting and IPN sources from the player's own direct ender items and shulker contents without opening an ender chest. Carried sources take priority.
- IPN tool swaps equip the replacement and return the surviving old tool to the source box's original spare-tool slot in one server transaction, preserving all components. Consumables keep IPN's existing swap flow.
- New server `playerEditableSettings` lists individually permitted player options. Locked options enforce server values across GUI, commands, synchronization and gameplay. Omitting the list retains prior all-options behavior, subject to `allowPlayerSettings`.
- Existing `configVersion: 2` files and personal choices are retained. Revoked choices become dormant rather than being deleted.

GUI, schematic and IPN protocols changed; update both sides to 0.5.0 for these features. Container and trade storage remain server-only compatible. Menu storage does not drop items to make space, and post-cursor collection does not displace existing inventory items. See the [user guide](../en/guide.md).
