# Magic Shulker Boxes 0.6.0

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- 管理员可通过 `/msb admin player <玩家名|UUID> show|set|reset` 查看、修改或重置指定玩家个人设置，支持离线 UUID；显示个人值、继承、锁定状态和实际生效值。
- 全部个人与服务器设置提供 Carpet 风格的聊天按钮：点击预览完整命令，按回车才执行。包括布尔值、模式值、继承/默认和逐项权限；仅服务端安装也能使用聊天按钮。
- 新增服务端 `admin show [选项]`、`admin set`、`admin reset <选项>`、`admin permission`、`admin permissions all|none`；普通玩家可 `reset <选项>` 恢复单项继承。
- 全部 20 个个人布尔选项提供独立客户端快捷键，默认未绑定。玩家自行绑定键盘或鼠标按键，服务器不接收或限制绑定；设置值仍遵守服务器总开关和逐项授权。无需 Mod Menu 或 YACL。
- `craftRefill` 默认改为 `false`。已有显式 `true` 保持开启，未设置时默认关闭；可通过设置、命令或快捷键开启。

保留 `configVersion: 2` 和 v4 设置协议，不重置已有文件。在线管理修改同步到模组客户端；离线修改仍可能被客户端下次入服上传的本地个人配置覆盖。详见[使用说明](../guide.md)。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- Administrators can inspect, edit or reset another player's preferences with `/msb admin player <name|UUID> show|set|reset`, including offline UUIDs. Output separates stored, inherited, locked and effective values.
- All personal and server settings have Carpet-style chat buttons. Click to preview a complete command; Enter applies it. Boolean values, modes, inheritance/defaults and individual permissions are covered. Chat buttons work with a server-only installation.
- New server `admin show [option]`, `admin set`, `admin reset <option>`, `admin permission` and `admin permissions all|none`; personal `reset <option>` restores one inherited value.
- All 20 personal boolean options have separate client key bindings, initially unbound. Players choose keyboard or mouse buttons locally; servers receive no bindings and cannot restrict the chosen keys. Setting values still respect master and per-option permissions. Mod Menu and YACL are optional.
- `craftRefill` now defaults to `false`. Existing explicit `true` values remain enabled; omitted values default to off. Enable it through settings, commands or a chosen key binding.

Existing files retain `configVersion: 2` and the v4 settings protocol. Online administrator edits synchronize to modded clients; offline edits may still be replaced by local preference uploads on the next login. See the [user guide](../en/guide.md).
