# Magic Shulker Boxes 0.6.1

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- 合成补货 `craftRefill` 恢复默认开启；新配置和未填写此字段的配置使用 `true`。
- 已有明确设置为 `false` 的服务器或个人配置保持关闭，文件不会因升级重置。仍可通过设置、命令或个人快捷键切换。
- 保留 0.6.0 的管理员玩家设置管理、全部设置点击命令预览和 20 个个人布尔快捷键。配置版本仍为 2，设置协议仍为 v4。

参见[使用说明](../guide.md)。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- Crafting refilling (`craftRefill`) defaults to enabled again. New configurations and omitted fields use `true`.
- Existing explicit `false` server or personal choices remain disabled; upgrading does not reset files. Settings, commands and personal key bindings can still switch it.
- Retains 0.6.0 administrator player management, clickable command previews for every setting and all 20 personal boolean key bindings. Configuration version 2 and the v4 settings protocol are unchanged.

See the [user guide](../en/guide.md).
