# Magic Shulker Boxes 0.9.0

适用于 Minecraft 1.21.11 / Fabric / Java 21。

- 开启自动收纳后，默认先使用可用同类盒，再放背包，最后使用空盒收纳余量。新增 `preferEmptyBoxesOverInventory=false`，开启后无同类盒时也优先尝试空盒或安全拆盒。
- 移除杂物盒分类及混装开关。拾取、容器收纳、原理图/IPN 取料、工具替换与合成补货统一将腾栏物品放入同类盒或独立空盒；无法完整规划时保持物品原样。原有含多种物品的盒子仍可作为取料来源。
- 新增独立 `spaceFailureMessages=true`（空间不足提示）。支持服务端默认、获授权的个人选择、命令、GUI 和默认未绑定的快捷键；所有入口共享 40 tick 限频。关闭只隐藏提示，`refillFailureMessages` 独立控制其他补货失败提示。
- 旧混装选项及许可在原字节 `.pre-single-type.bak` 备份后移除；`onlyWhenInventoryFull` 反值迁移为 `preferEmptyBoxesOverInventory` 并重命名许可。其他选择保留，冲突备份和无效文件不覆盖。缺少新提示字段时默认开启，已有精确权限白名单保持原样。
- 个人设置和 GUI 协议升级为 **v7**，客户端与服务端需同时升级。磁盘仍为版本 2；原理图、IPN 和末影箱来源协议格式保持不变。
- 设置界面跳过没有选项的分组，避免空分组导致 YACL 打开失败。Carpet 堆叠盒与 GCA 假人补货职责保持不变。

设置方法见[使用说明](../guide.md)。服务器和 AutoModpack 客户端来源由[手动部署命令](../release-staging.md)同步更新。

## English

For Minecraft 1.21.11 / Fabric / Java 21.

- Enabled pickup storage now uses matching boxes first, then inventory space, then empty boxes for overflow. Enable `preferEmptyBoxesOverInventory` (default `false`) to try empty or safely split boxes before inventory too.
- Removes mixed-box classification and mixing settings. Pickup, container storage, schematic/IPN extraction, tool replacement and crafting relocate items into matching single-type or separate empty boxes. Incomplete plans leave items unchanged. Existing boxes containing multiple types remain valid extraction sources.
- Adds independent `spaceFailureMessages=true`, available through server defaults, permitted personal choices, commands, GUI and an initially unbound key binding. All paths share a 40-tick cooldown. Disabling it only hides space notices; `refillFailureMessages` separately controls other refill failures.
- Retired mixing options and permissions are removed after an exact-byte `.pre-single-type.bak` backup. `onlyWhenInventoryFull` migrates to the inverse `preferEmptyBoxesOverInventory` value and renames its permission. Other choices remain intact; malformed files and conflicting backups are preserved. Missing notice fields default on; existing explicit permission lists remain unchanged.
- Settings and GUI protocols advance to **v7**, requiring both sides to update. Disk schema stays at version 2; schematic, IPN and ender-source protocol formats are unchanged.
- Skips empty settings groups to prevent YACL screen failures. Carpet stacking compatibility and GCA ownership of fake-player replenishment remain unchanged.

See the [user guide](../en/guide.md). [Manual deployment](../en/release-staging.md) updates server and AutoModpack client sources together.
